# 📚 Avaliação Individual – Front-End Essencial

Este repositório contém os exercícios desenvolvidos para a avaliação da disciplina de **Front-End Essencial**, com foco em HTML e CSS.

## 🗂️ Estrutura do Projeto

O projeto foi organizado em pastas separadas para cada exercício, seguindo o padrão solicitado:

---

## 🧩 Exercício 01 – Página Pessoal

Criação de uma página HTML com uma breve apresentação pessoal.

### 🔹 Conteúdos incluídos:
- Título principal com meu nome  
- Parágrafo de apresentação  
- Lista com hobbies/interesses  
- Imagem representativa  
- Link para rede social (GitHub/LinkedIn)  

### 🎨 Estilização (CSS):
- Cor de fundo personalizada  
- Diferenciação de cores entre título e texto  
- Ajuste de tamanho da imagem  
- Uso de `margin` e `padding` para espaçamento  

---

## 🛒 Exercício 02 – Card de Produto

Desenvolvimento de um card de produto para uma loja virtual.

### 🔹 Elementos do card:
- Imagem do produto  
- Nome em destaque  
- Descrição curta  
- Preço  
- Botão de compra  

### 🎨 Técnicas utilizadas:
- Organização com `div`  
- Estilização com bordas, sombras e cores  
- Uso de `flexbox` para alinhamento (quando necessário)  

---

## 📐 Exercício 03 – Layout com Flexbox

Reprodução de um layout utilizando **Flexbox**.

### 🔹 Conceitos aplicados:
- `display: flex`  
- Alinhamento horizontal e vertical  
- Distribuição de elementos na tela  
- Estruturação de layout responsivo básico  

---

## 🚀 Tecnologias Utilizadas

- HTML5  
- CSS3  

---

## 💡 Objetivo

O objetivo desta atividade foi praticar:
- Estruturação de páginas com HTML  
- Estilização com CSS  
- Organização de projetos  
- Uso de Flexbox para layout
